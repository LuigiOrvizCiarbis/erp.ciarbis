Qué es BIMS ERP

BIMS — Business Intelligent Management Systems es un sistema WebApp inteligente para la gestión de tu negocio: ERP + CRM + IA, todo en un lugar. Desarrollamos soluciones especializadas por vertical, que integran y ordenan la información de todas las áreas del negocio y utilizan Agentes IA para atender clientes, automatizar procesos y ayudar a la gerencia en la toma de decisiones.

Ingreso al sistema

  1. Abrir el navegador de internet.
  2. Ingresar a la plataforma de BIMS (erp.ciarbis.com).
  3. Registro de cuenta gratis.

Durante el registro, el usuario selecciona el tipo de negocio (kiosco, almacén, showroom, etc.), lo que permite al sistema auto-configurarse con los módulos pertinentes, además de permitir la gestión de múltiples sucursales y roles de usuario definidos como dueño, sucursal, empleado o super administrador.

Recomendación: cada usuario debe tener su propia cuenta y no compartir su contraseña.

Menú de navegación

El menú principal (izquierda) tiene una versión contraída y otra expandida. Cada ítem lleva a un módulo del sistema:

Inicio
Dashboard principal, reportes y métricas generales de todo el negocio.
Inventario
Control de todo el stock del negocio.
Ventas
Registro de todas las ventas del negocio.
Clientes
Registro de todos los clientes y módulo integrado de CRM.
Compras
Registro de todas las compras y órdenes de compra.
Caja
Sistema de caja o punto de venta, con lectura de código de barra y emisión de ticket X y fiscal.
Fichaje
Registro de fichajes de entrada, descanso y salida de los empleados.
Finanzas
Donde el contador puede controlar la situación contable.
Auditoría
Control y registro de todos los cambios realizados por empleados y dueños en caja, fichajes y stock.
Ajustes
Configuración de todo el negocio: usuarios, empresa, facturación, caja, sucursales, medios de pago, listas de precio, cupones y puntos, entre otros.

Pantalla principal

Desde el menú principal se pueden encontrar las métricas y las diferentes opciones del sistema: accesos directos a cada módulo, un resumen (productos, clientes, ventas acumuladas, OV registradas) y una sección de reportes y métricas con selector de período.

Precio del dólar

También se puede ver el precio del dólar en tiempo real (Oficial, Blue, USDT y un valor Manual). Se puede actualizar la información y seleccionar con una estrella el valor preferente o más utilizado. Además se puede establecer un valor manual, según lo desee el usuario. En la campanita de arriba a la derecha aparecen alertas por stock bajo, cajas abiertas o vencimientos próximos.

Centro de control

Desde acá se puede elegir tener un panorama completo como administrador, vendedor, depósito o contador; también existe la opción de visualizar las métricas en dólares o en pesos (vía API), y elegir entre modo oscuro y modo claro. Otras opciones ubicadas en el centro de control son: editar perfil, editar empresa y temas — estos botones redirigen a la opción de Ajustes.

Opción Ajustes

Empresa

El usuario puede cargar datos de la empresa, como el CUIT, su condición de IVA y también realizar la configuración para emitir facturas.

Mi perfil

El usuario puede editar su perfil y personalizarlo a su manera.

Usuarios

El super administrador puede crear usuarios y establecer sus roles: administrador, vendedor, depósito, producción, contador o logística. También se puede crear otro rol a medida.

Módulos

Si se necesita un nuevo módulo, se puede solicitar presionando el botón "Solicitar activación de módulos", que redirige a WhatsApp para recibir asistencia.

Razones sociales

Se pueden agregar las razones sociales que utiliza el negocio, y al momento de facturar hay que seleccionar con cuál se quiere realizar la factura.

Empleados

Es posible gestionar diversas sucursales y asignar empleados con un número de legajo y un PIN de seguridad personal, obligatorio para que el personal pueda realizar el fichaje de entrada/salida, así como para abrir y cerrar la caja.

Fichaje

El sistema permite ver y exportar el historial de fichajes a un archivo de Excel para su posterior revisión.

Roles

Se pueden ver todos los roles y eliminarlos si así se desea.

Sucursales

Se pueden crear sucursales y determinar cuál es la principal. Arriba a la derecha hay un selector para elegir qué sucursal visualizar, o "Todas las sucursales" para ver los números macro.

Caja

Para operar el punto de venta, el usuario puede vincular la cuenta con ARCA para la emisión de facturas y seleccionar el tipo de impresora de tickets (58 u 80 mm). Además, desde esta sección se pueden configurar etiquetas para los productos, con distintas opciones de etiquetado según las necesidades del usuario. Se implementa un sistema de seguridad mediante PIN, que permite autorizar la eliminación de productos en la caja para evitar errores o fraudes, dejando un registro de auditoría de cada acción realizada.

Variantes y lista de precios

El sistema permite configurar variantes de producto como peso, talla o sabor.

Lista de precio

Se pueden gestionar diversas listas de precios para distintos tipos de clientes (mayorista, minorista, distribuidor). Además, se pueden crear categorías y subcategorías y aplicar márgenes de ganancia predeterminados a nivel general o por categoría.

Cupones

Es posible crear cupones de descuento con vigencia definida, límites de uso total y restricciones por cliente, permitiendo combinar o excluir estos descuentos con las listas de precios preexistentes.

Puntos

El sistema incluye un programa de fidelización basado en puntos, donde el usuario define reglas de acumulación y condiciones de compra mínima para canjear recompensas. También permite realizar bonificaciones tipo 2x1.

Método de pago

Relacionado con el pago de suscripciones — por este medio se elige cómo se quiere recibir el pago.

Temas

Opción para personalizar los colores y medidas del sistema.

Inventario

En este módulo se pueden cargar nuevos productos a través del botón "+ Nuevo producto". Esta sección permite definir descripción corta y larga, proveedor, código de barras (escaneable con pistola), precio de costo y venta, stock inicial, stock mínimo (el sistema avisa cuando se alcanza) y fechas de vencimiento.

  • El sistema soporta la creación de variantes, donde cada una puede tener características distintas (como tamaño o sabor); si el usuario olvida grabar una variante, debe asegurarse de confirmar la acción para que quede guardada correctamente.
  • El sistema facilita la edición de stock de manera masiva, la carga de productos mediante Excel, y el registro de "mermas" por roturas, vencimientos o errores, asegurando que cada diferencia de stock quede registrada para su futura auditoría.
  • Al modificar el stock, el sistema obliga al usuario a dejar una justificación, manteniendo la integridad del registro.
Importante: no tocar el SKU — se genera solo.
La opción Modificar stock solo se usa para cambios generales en depósito; para el ingreso de mercadería se opera desde Compras.

Compras

  • El módulo de compras permite registrar proveedores.
  • Genera órdenes de compra especificando cantidades y precios, y confirma la recepción de la mercadería.
  • Permite gestionar cuentas corrientes: el usuario puede ver el historial de deudas, realizar pagos desde la caja o fondos propios, y reducir la deuda pendiente con el proveedor.

Caja

  • Tras realizar el fichaje, el empleado puede abrir la caja con un fondo inicial, procesar ventas, aplicar descuentos o cupones, y registrar pagos mediante diversos medios (efectivo, QR, etc.). Es posible imprimir tickets no fiscales y fiscales al finalizar la operación.
  • Anulación de tickets y notas de crédito: ante una facturación errónea o si un cliente desiste de una compra, el usuario puede realizar una nota de crédito, incluso para tickets no fiscales, buscando el comprobante por su número único. Estas acciones quedan registradas en el sistema de auditoría, lo que permite al dueño monitorear posibles irregularidades o fraudes.
  • Cierre de caja y auditoría final: al finalizar el turno, el usuario cierra la caja contando el efectivo presente y comparándolo con el sistema, que discrimina automáticamente las ventas por medio de pago (efectivo, QR, transferencia, etc.).

Ventas

El sistema permite buscar y revisar el detalle de las ventas pasadas utilizando el número de ticket o, en caso de pérdida, ordenando las ventas por horario o fecha, lo cual facilita la gestión de cambios y devoluciones.

  • Personalización: el usuario puede adaptar la interfaz de venta eligiendo entre vista de grilla, categorías, e-commerce o lista tradicional, además de editar el ancho, orden y visibilidad de las columnas para optimizar la experiencia de uso según sus preferencias personales.

Finanzas

  • El módulo de finanzas permite registrar gastos operativos, como el pago de servicios (ej. luz), categorizarlos, asignar la sucursal y el medio de pago (caja o transferencia del dueño).
  • El sistema muestra el libro contable con el neto del día, ingresos totales y egresos, proporcionando una métrica general en el panel principal.
  • Emisión de comprobantes e ingresos externos: además de los tickets de venta, es posible emitir facturas (A, B o C) a través del sistema en el módulo Finanzas, y registrar ingresos externos provenientes de inversiones, plazos fijos u otras ventas por fuera de la operatoria habitual de caja.
  • El dueño puede ver el historial detallado de cierres en auditorías para verificar si hubo discrepancias o si la caja cuadró correctamente.

Auditoría

  • Registro de acciones realizadas por los usuarios.
  • Control de anulaciones, notas de crédito y eliminaciones de productos.
  • Registro y justificación de ajustes y mermas de stock, y movimientos de proveedores.
  • Historial de fichajes y cierres de caja.

Clientes

  • Gestión de clientes y tipos de cliente.
  • Consulta de historial de compras.
  • Gestión de cambios, devoluciones y notas de crédito.
  • Emisión de comprobantes y registro de medios de pago.

Fichajes

  • Registro de entrada y salida mediante PIN personal.
  • Asociación del empleado con su sucursal y legajo.
  • Habilitación para abrir y cerrar la caja.
  • Consulta y exportación del historial de fichajes.

Recomendaciones de uso

  • No compartir usuarios ni contraseñas.
  • Revisar los datos antes de confirmar una operación.
  • Realizar controles periódicos de stock.
  • Cerrar la caja luego de cada turno.
  • Informar inmediatamente cualquier dificultad o error que se encuentre.
  • Si tiene alguna sugerencia o necesidad puntual que todavía no contemple la aplicación, también puede comunicarse.
